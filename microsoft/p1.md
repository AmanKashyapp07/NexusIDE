## 1. Core Concept & Architectural Trade-Offs

```
┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
│                             YJS CRDT DATA STRUCTURE IN MEMORY                                    │
└──────────────────────────────────────────────────────────────────────────────────────────────────┘

 Text is modeled as a doubly-linked list of immutable Item blocks in RAM:

  ┌────────────────────┐         ┌────────────────────┐         ┌────────────────────┐
  │ Item 1             │ ◄─────► │ Item 2             │ ◄─────► │ Item 3             │
  │ ID: (UserA, 1)     │         │ ID: (UserB, 1)     │         │ ID: (UserA, 2)     │
  │ Left: null         │         │ Left: (UserA, 1)   │         │ Left: (UserB, 1)   │
  │ Content: "const "  │         │ Content: "x "      │         │ Content: "= 10;"   │
  │ Deleted: false     │         │ Deleted: false     │         │ Deleted: false     │
  └────────────────────┘         └────────────────────┘         └────────────────────┘
```

### Comparative Architecture Table: CRDT vs. OT vs. Automerge

| Feature / Metric | Centralized OT (Google Docs / Etherpad) | Yjs CRDT (NexusIDE) | Automerge (JSON CRDT) |
| :--- | :--- | :--- | :--- |
| **Coordination Model** | Centralized Lockstep Sequencer (Single Master) | **Stateless Mesh (Join-Semilattice)** | Stateless Mesh (State-based) |
| **Mathematical Axiom** | Global Operational Transformation Log | **$A \sqcup B = B \sqcup A$ (Commutative)** | Graph causal history comparison |
| **Multi-Pod Scalability** | **Brittle** (requires sticky routing to sequencer) | **Infinite Horizontal Scale** (via Redis) | Horizontal Scale (higher memory) |
| **Wire Protocol Overhead** | Small (plain index offsets: `ins(12, 'x')`) | **Low** (compact binary bit-packed deltas) | High (verbose column-oriented log) |
| **Memory Footprint** | Low (plain string buffers) | **Medium** ($1.5\times$ raw text via chunking) | High ($5\text{–}10\times$ raw text) |
| **Convergence Guarantee** | Vulnerable to race conditions / out-of-order | **Strong Eventual Consistency (SEC)** | Strong Eventual Consistency (SEC) |

## 3. Binary Wire-Format & Networking Architecture

### 8-Byte Fixed-Width Cursor Packet Layout (`cursorCodec.service.ts`)

```
 0                   15 16                  31 32                  47 48                  63  (Bits)
┌──────────────────────┬──────────────────────┬──────────────────────┬──────────────────────┐
│  userHash (uint16)   │  lineNumber (uint16) │ columnNumber(uint16) │ selectionLen(uint16) │
│       2 Bytes        │        2 Bytes       │        2 Bytes       │        2 Bytes       │
└──────────────────────┴──────────────────────┴──────────────────────┴──────────────────────┘
 Total Wire Size: Exactly 8 Bytes (vs ~95 Bytes in JSON -> 91% network payload reduction!)
 Zero V8 Garbage Collection: DataView reads/writes directly in sub-microsecond CPU cycles.
```

## 4. Visual Failure Modes & Recovery Mechanics

```
┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
│                         5 CRUCIAL FAILURE MODES: SYSTEM BEHAVIOR MATRIX                          │
└──────────────────────────────────────────────────────────────────────────────────────────────────┘
```

| Failure Mode | Root Trigger | Immediate System Impact | Recovery / Mitigation Mechanism | Automated Verification |
| :--- | :--- | :--- | :--- | :--- |
| **1. Mid-Edit Network Drop** | Client Wi-Fi drops while typing 50 chars. | Client has uncommitted local updates; peer deletes line. | On reconnect, exchange **State Vectors** (`Map<Client, Clock>`). Minimal binary diff sent; CRDT converges deterministically. | `test.sh --idempotency` & `test.sh --ws` |
| **2. Slow Client Congestion** | Throttled 2G cellular client falls behind. | Socket TCP send queue bloats, threatening Node.js heap RAM. | Backpressure guard drops awareness at **1MB** buffer; terminates stalled socket at **5MB** via `ws.terminate()`. | `test.sh --ws` (`websocket_backpressure.test.ts`) |
| **3. Memory Slab Corruption** | Node.js allocates small buffers in 8KB pool. | Passing buffer to `new Uint8Array(buf)` reads from index 0. | Enforce offset-aware instantiation: `new Uint8Array(buf.buffer, buf.byteOffset, buf.byteLength)` across all decoders. | `test.sh --property` (fast-check buffer fuzz) |
| **4. Out-of-Order Packet Arrival** | Route flapping causes Update 2 to arrive before Update 1. | Parent clock reference missing in local StructStore. | Yjs holds update in internal causality queue; applies atomically as soon as missing clock arrives. | `test.sh --property` (randomized packet order) |
| **5. Document History Bloat** | Days of continuous edits leave tombstone markers. | In-memory `WSSharedDoc` grows from 50KB to 10MB+. | Offload periodic compaction (`Y.encodeStateAsUpdate`) to `worker_threads` pool (`casWorker.js`), keeping event loop lag <0.8ms. | `test.sh --crdt-stress` (10,000 edits compacted) |

## 6. Microsoft-Specific Technical Anchors

### Connection to Visual Studio Code & Monaco Editor
- **Piece Tree Data Structure:** Monaco stores text inside a red-black balanced tree of buffer slices (Piece Table). When our Yjs engine merges CRDT updates, Monaco's `applyEdits()` modifies the Piece Tree in $O(\log N)$ time, avoiding full-document string reallocation.
- **VS Code Live Share Contrast:** Live Share shares language servers from a host machine via RPC, but serializes edits through an operational transform coordinator. NexusIDE uses a browser-first, cloud-native model where all clients are symmetric peers on a headless cloud CRDT.

### Connection to Azure Web PubSub
- At hyperscale, hosting persistent WebSockets inside compute pods causes stateful coupling. Azure solves this via **Azure Web PubSub** (managing TCP at the edge and pushing CloudEvents to worker functions).
- NexusIDE mirrors this exact separation using raw WebSocket ingress decoupled from storage via our Redis Pub/Sub mesh.
