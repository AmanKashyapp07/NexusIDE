## 4. Top 10 Socratic Probing Questions: Visual Defense Matrix

```
┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
│                         TOP 10 INTERVIEWER GOTCHAS: VISUAL DECISION MATRIX                       │
└──────────────────────────────────────────────────────────────────────────────────────────────────┘
```

| # | Question / Probe | Architectural Core | Grounded Candidate Response |
| :---: | :--- | :--- | :--- |
| **1** | **"Why CRDTs over OT?"** | Multi-Pod Scaling | OT requires a centralized sequencer (bottleneck). CRDTs satisfy join-semilattice math ($A \sqcup B = B \sqcup A$), allowing any pod to merge independently. |
| **2** | **"How break Redis storm?"** | Message Provenance | Incoming Redis updates are tagged with `origin: 'redis'`. Outbound publisher gates on `if (origin !== 'redis')`, deterministically breaking feedback loops. |
| **3** | **"Redlock Martin Kleppmann critique?"** | Safety vs Efficiency | Redlock is an efficiency lock (stops duplicate flushes). True safety is enforced in PostgreSQL via `ON CONFLICT DO NOTHING` and monotonic fencing tokens. |
| **4** | **"Why 1 container / workspace?"** | Host Density & Builds | Cuts host RAM by 80–90%; shared volume lets User B see User A's build output. Isolated PTYs (`/dev/pts/X`) preserve private bash history and Git author. |
| **5** | **"Are containers secure enough?"** | Shared Kernel Escape | Containers share host Linux kernel; fork bombs are blocked via `pids.max=500`, but enterprise evolution requires microVMs (Azure Kata / AWS Firecracker). |
| **6** | **"Why custom CAS vs git CLI?"** | Multi-Tenant Concurrency| `git` CLI requires disk locks and OS process forks (150ms). Relational CAS in Postgres gives Git's deduplication with ACID transactions and covering indexes. |
| **7** | **"Why offload hashing to workers?"**| Node Event Loop Lag | SHA-256 hashing 300 files freezes single-threaded Node for 140ms. Offloading to OS `worker_threads` keeps p99 event loop lag strictly under 0.8ms. |
| **8** | **"How bundle 4.68MB -> 609KB?"** | Rollup Chunking & rAF | Vite Rollup `manualChunks` isolates Monaco and React into permanent cache chunks. Monaco `deltaDecorations` with `requestAnimationFrame` locks paint to 60 FPS. |
| **9** | **"Timelapse under 12MB RAM?"** | Sparse Keyframing | Caches 1 state vector every 25 edits ($K=25$). Replays $\le 24$ micro-updates on the fly; headless `Y.Doc` with `gc: false` preserves tombstones for attribution. |
| **10**| **"Hardest bug personally solved?"** | V8 Buffer Pool Offset | Node slices small buffers from shared 8KB pool. `new Uint8Array(buf.buffer)` ignored `byteOffset`, reading offset 0. Fixed via `new Uint8Array(buf.buffer, buf.byteOffset, buf.byteLength)`. |
